# ИИ-инструкция: совместимый вход

Файл оставлен для совместимости. Каноника:

- `PROMPT.md` / `PROMPT-RU.md` — режим работы
- `START-HERE.md` / `START-HERE-RU.md` — быстрый старт
- `README.md` / `README-RU.md` — справка
- `CHANGELOG.md` — история версий
- `templates/` — шаблоны
- `IMPORT-SOP-RU.md` — русская справка для импортов

Правила: шаблоны на английском; import-шаблон в `templates/IMPORT-SOP.template.md`; обновления проверять не чаще 1 раза в 7 дней; `.gitignore` должен исключать state-файлы, секреты, логи и локальные артефакты.
